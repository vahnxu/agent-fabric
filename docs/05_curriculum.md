# 第五部分 · 课程与演讲大纲 (The Curriculum)

> **本大纲可直接作为 60 分钟技术演讲、系列长文或线下 Workshop 的标准大纲。**

---

| 讲次 | 核心模块 | 核心概念与因果链 | 对应教案案例 | 学员即刻可带走的产出物 |
|---|---|---|---|---|
| **第 1 讲** | **新经济学：为什么是超级组织** | 制度化边际成本塌缩；从“玩具级 Prompt”到“工业级 Fabric” | 案例 1：精确提交 | 评估自己当前所处的 Agent 阶段（第 1 天 vs 第 90 天） |
| **第 2 讲** | **核心认知跃迁：文本负债 vs 机制资产** | 软法与硬法的本质差异；注意力预算守恒定律 | 案例 2：可逆第一步 | 将团队或个人的所有 Prompt 梳理为“文本/机制”对照表 |
| **第 3 讲** | **最小内核：三角色与三文件起步** | 人当立法者，AI 当编译器，Git 当档案室；四条基本法 | 案例 6：黑名单必复发 | 现场创建个人的第一版 `RULES.md` 和 `INCIDENTS.md` |
| **第 4 讲** | **移动总机模式与长驻自愈** | 接线不干活；物理防爆 Context；50MB 阈值原子换壳 | 案例 8：总机换壳自愈 | 搭建一套基于移动端无感派单与自愈的架构 |
| **第 5 讲** | **Git SRE 级门禁与多模型解耦** | 待推提交全绿防线；Core 与 Claude/Codex/Gemini 解耦 | 案例 4：待推全绿防线 | 部署第一个 PreToolUse 物理拦截钩子与 Pre-push 门禁 |
| **第 6 讲** | **防幻觉与不可逆操作红线** | 否定式取证穷举；机密安全管道；数字强 Readback | 案例 5：否定式断言取证 | 为生产系统安装事故驱动的五步复利飞轮 |
| **第 6.5 讲** | **门禁必须证明自己拒绝了什么** | 跑绿 ≠ 生效；负向用例与防误伤用例缺一不可；门禁自陈不覆盖面 | 案例 9：只走顺路的测试套件 | 给已有的每道门禁补一条「它必须拦住」的用例，跑一次看是否真的红 |
| **第 7 讲** | **多机对等拓扑与规矩长效维护** | Git bare 秒级事件同步；独立审计；防止制度退化 | 案例 7：读侧对称与审计 | 制定一套每个季度运行一次的 Agent 治理体检脚本 |
